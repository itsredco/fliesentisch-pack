# FliesentischMC – Pack-Dateien

Dieses Repository liefert die Mod-Liste für den Minecraft-Server FliesentischMC aus. Spieler laden es nicht von Hand: Ihre Prism-Instanz holt sich beim Start `pack.toml` (packwiz) und lädt nur geänderte Dateien.

Fast alle Mods kommen direkt vom Modrinth-CDN (siehe die `*.pw.toml`-Dateien). Hier liegen nur Dateien, die es dort nicht gibt.
